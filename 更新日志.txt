#	问题	修复方式
1	手机端筛选抽屉不弹出	updateLayoutVisibility() 中的内联 style 覆盖了 CSS class 的 transform，导致 .open 类无法生效。改为全部通过 CSS + class 控制，JS 只做 class 切换。同时 .phone-mode 的 CSS 规则直接写在全局，不依赖媒体查询
2	图标反了 + 蓝色背景	toggleRespMode() 中修复图标逻辑：默认显示 📱（当前是桌面模式）→ 点击切换到手机模式，图标变为 💻。移除了 classList.toggle('active')，切换视图不再有背景色变化
3	日期输入框显示不全	筛选面板宽度从 280px → 320px，日期 input 两边的 — 分隔符确保均匀分布
4	单字段筛选放在同一行	搜索、最低投票、年份、语言、地区 改为 .filter-row-inline（label 和 input 同行）
5	添加"应用筛选"按钮	面板顶部第一个元素是 ✅ 应用筛选 按钮（flex-shrink:0 冻结），所有筛选变更只保存到 state，只有点击"应用"或"重置"才真正发起请求。切换电影/电视剧仍即时刷新
6	胶囊子按钮用椭圆	.pill-toggle .pill-btn:first-child / :last-child 分别设置 border-radius，子按钮两端变成半圆
